# SCEE-mc

**SCEE-mc** is a private customization of [Helium314/SCEE](https://github.com/Helium314/SCEE)
(itself based on [StreetComplete](https://github.com/streetcomplete/StreetComplete)).

| | |
|---|---|
| Android application id | `de.westnordost.streetcomplete.expert.mc` |
| Launcher name | `SCEE-mc` |
| OAuth redirect | `sceemc://oauth` |
| License | [GPL-3.0](LICENSE) |

Installs alongside StreetComplete and upstream SCEE. See the [README](README.md) and
[signed APK / GitHub Release guide](res/documentation/scee-mc-github-release.md).
